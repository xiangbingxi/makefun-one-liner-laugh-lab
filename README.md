Entry for the [One-Liner Laugh Lab](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae) competition on make.fun.

## The line

> I bought a shredder with a reverse button, which feels optimistic for a machine whose only job is making irreversible decisions.

128 characters — inside the 200-character limit.

## How it works

`main.py` writes that exact line to `/output/entry.txt`: UTF-8, no trailing
newline, no external files, no network. After writing, it reads the file
back and checks it matches the line character for character, exiting with
an error if it does not.

## Run

```sh
python3 main.py
```
